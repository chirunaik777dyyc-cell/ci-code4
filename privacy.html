Data Protection & Privacy

Privacy Policy

Compliant with India Digital Personal Data Protection (DPDP) Act & Global GDPR Standards

1. Local & Cloud Code Execution

JavaScript runs in a time-limited browser worker, Python runs in a dedicated Pyodide WebAssembly worker, SQL uses SQLite WebAssembly in the browser, and HTML is shown in a sandboxed preview. These local modes do not intentionally send your source code to the compiler service, although browser libraries are downloaded from external CDNs. For languages using online compilation, the code and standard input are sent over HTTPS through this site's execution endpoint to the third-party Piston compiler service. Do not submit passwords, API keys, personal information, or confidential code. Local editor/project state is stored in your browser when local storage is available; share links include the active file's code in the URL hash.
